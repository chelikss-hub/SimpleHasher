# SimpleHasher

# 🧂 Hasher — простая утилита для хеширования строк

Маленькая консольная программа на Python, которая считает хеш строки по выбранному алгоритму.

---

## 📦 Что умеет

- Поддерживаемые алгоритмы:
  - `md5`
  - `sha1`
  - `sha256`
  - `sha512`
- Работает в цикле — не надо перезапускать
- Выводит результат сразу

---

## 🚀 Запуск

```bash
python main.py
